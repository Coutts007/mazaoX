# Site images

Put your own images here. File names are configured in `src/config/images.ts`.

| File | Where it shows | Suggested size |
|---|---|---|
| `hero.jpg` | Home page hero background | 1920×1080 or larger |
| `auth-bg.jpg` | Login and register background | 1600×1000 |
| `cta-band.jpg` | "Grow with MazaoX" band (home, signed out) | 1600×600 |
| `listing-placeholder.jpg` | Listings that have no uploaded photo | 800×600 |
| `step-1.jpg` … `step-3.jpg` | "How it works" steps | 800×600 |
| `categories/<slug>.jpg` | Shop-by-category tiles and listings with no photo | 600×600 |

Any file that is missing is skipped and a plain colour is shown instead. Farmers' listing photos are uploaded by users and are not stored here.
